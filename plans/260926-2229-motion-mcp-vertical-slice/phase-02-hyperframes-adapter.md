## Requirements
1. **Compiler** `compileProject(ir: MotionIR, outDir, opts?) → { projectDir, files, compositionId, duration }`: writes a HyperFrames project: `index.html` root (data-composition-id, width/height/duration), one sub-composition per scene in `compositions/<sceneId>.html` (host div with `data-composition-src`, `data-start`, `data-duration`; child `<template>` with its own paused GSAP timeline registered in `window.__timelines`), `hyperframes.json`, and `motion-ir.json` (the IR, for traceability). Deterministic output (same IR → byte-identical files). Map tokens: easing tokens → GSAP eases (`decelerate`→`power3.out`, `standard`→`power2.inOut`, `emphasized`→`expo.out`, `accelerate`→`power2.in`, `linear`→`none`, `spring-soft`→`back.out(1.4)`, `snap`→`power4.out`); size tokens → px scaled by frame height; color tokens → brand colors via CSS variables; layout templates → CSS grid/flex; every `MotionPrimitive` implemented (count-up via a tweened proxy object updating text; type-on via clip or characters; draw via scaleX/stroke-dashoffset; mask-reveal via clip-path inset; stagger-in over list items/words). Beat timing: numbers, `{after}` and `{with}` resolved to absolute scene-local seconds. Transitions in/out: at least cut, fade, slide-left, slide-up, wipe, mask, scale-through (match-cut may degrade to cut). Respect determinism rules: no Date/rAF/unseeded random, no CSS animations, no `repeat:-1`, end timeline with `tl.set({}, {}, duration)`, `immediateRender:false` where tweens share targets. Fonts: must render deterministically offline if possible — investigate the HyperFrames font handling (`hyperframes-localize-fonts`, compiler font embedding) and pick the most reliable approach; document it in a code comment. Escape all user text (HTML-escape). Code blocks rendered with mono font and simple token coloring is fine.
2. **Lint** in-process via `@hyperframes/lint` (`lintProject` or equivalent) → normalized `QaIssue[]` (category `lint_error` for errors, severity mapping).
3. **Check / snapshot / keyframes** via the pinned CLI `hyperframes@0.8.78` subprocess with `--json` (use `runCommand` + `scrubbedEnv` from `@motion-mcp/shared`, set `HYPERFRAMES_NO_TELEMETRY=1`, `HYPERFRAMES_NO_UPDATE_CHECK=1`, `HYPERFRAMES_SKIP_SKILLS=1`, pass `--describe false` to snapshot). Resolve the CLI from the package's installed bin (add `hyperframes` as an exact dependency) and run it with `process.execPath`. Normalize `check` JSON (runtime, layout overflow/overlap, contrast) into `QaIssue[]` with sceneId inferred from time and scene start offsets.
4. **Contact sheet**: snapshot N frames per scene (mid-hold points) and tile them with FFmpeg into one PNG (`packages/media/src/ffmpeg.ts` exposes `tileImages`, `finishMp4` (faststart, yuv420p, H.264 CRF 20, AAC 48k if audio), `probe` (ffprobe JSON → {width,height,fps,duration,codec,hasAudio}), `extractFrame`, `detectBlack`).
5. **Render** via `@hyperframes/producer` (`createRenderJob`/`executeRenderJob`) with quality presets: `preview` (draft, fps 15 or 24, output scaled down if supported — otherwise draft at native size), `final` (standard/high at native 1080p), `final-4k` accepted but may throw a clear not-supported error if the producer cannot upscale. Progress callback, AbortSignal, render duration reported. Fall back to the CLI `render` subprocess if the producer import fails at runtime. Then `finishMp4`. Return `{ outputPath, durationMs, probe }`.
6. `doctor()` → verifies Node, Chrome/headless-shell (`hyperframes browser ensure` if missing), FFmpeg/FFprobe; returns a structured report.
7. Export a small `HyperframesAdapter` interface (compile, lint, check, snapshot, contactSheet, render, doctor) so other renderers can implement the same shape later.
